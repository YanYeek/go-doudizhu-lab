# client — 游戏前端

Cocos Creator **3.8.8** 项目目录。

## 初始化方式

用 Cocos Dashboard 新建项目时，把项目位置选在本目录（`client/`），或新建后把工程内容移到这里。

## 目录说明（Cocos Creator 生成后）

- `assets/` —— 场景、脚本（TypeScript）、美术资源，**核心代码都在这**
- `settings/` —— 项目设置，需要提交
- `library/`、`temp/`、`build/`、`local/` —— 编辑器生成的缓存与构建产物，已在根 .gitignore 中忽略
