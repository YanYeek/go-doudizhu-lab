# ADR-0001：选择经典斗地主作为教程游戏

- 状态：已采纳
- 日期：2026-06-13

## 背景

项目目标不是尽快复制一款现成游戏，而是完整学习 Cocos Creator、Go、due、WebSocket、多人房间、规则测试和部署。早期曾研究《爆炸小黄人》，但它是具有明确品牌、角色和商业表达的现有产品。

## 决策

项目采用经典三人单副牌斗地主作为唯一活动开发方向。

第一阶段实现严格限定为：

- 三名玩家，一名地主对两名农民；
- 一副 54 张扑克牌；
- 基础叫分、出牌、过牌、胜负和基础计分；
- 不实现癞子、抢地主、明牌、加倍、欢乐玩法、货币系统和 AI。

项目规则以 [`docs/rules/doudizhu-rules.md`](../rules/doudizhu-rules.md) 为准。爆炸小黄人资料移入 [`docs/archive/exploding-minions/`](../archive/exploding-minions/)。

## 理由

- 斗地主规则本身适合公开讲解，教程可使用自制界面和普通扑克牌表达，知识产权风险相对低。
- 牌型识别、牌型比较、一手牌多种解释、隐藏信息和多人协作，能提供足够深入的全栈游戏开发练习。
- 三人固定局降低首个版本的房间和规则分支数量，便于先完成端到端联调。

## 后果

- 活动代码、配置、协议和文档统一使用 `doudizhu` 命名。
- 对存在平台差异的规则必须在项目规则文档中明确裁定，并用表驱动测试锁定。
- 公开教程不复用第三方斗地主平台的 UI、美术、音效、文案或源代码。
- 爆炸小黄人资料仅保留为历史档案，不继续实现。
