# 《爆炸小黄人》规则与卡牌效果

> 研究日期：2026-06-12  
> 用途：作为本项目服务端规则实现、协议设计和测试用例的依据。  
> 规则基准：用户持有的中文纸质版规则；已与 Exploding Kittens 官方英文说明书 v1.2（2023-09-15）交叉核对。

## 0. 项目规则来源优先级

本项目发生规则冲突时，按以下顺序裁定：

1. **用户持有的中文纸质版规则**：本项目实现的最高依据。
2. **纸质版实体卡牌上的文字**：某张牌的具体卡面文字优先于通用说明。

5. **第三方规则网站或社区讨论**：只能辅助理解，不能覆盖以上来源。

### 纸质版核对结果

- 共 72 张牌，支持 2～5 人。
- 2 人使用带“格鲁科技符号”的 31 张普通牌；3 人使用不带符号的 37 张普通牌；4～5 人使用全部 68 张普通牌。
- 每人先获得 1 张拆弹，再发 7 张牌；加入数量为玩家数减一的爆炸小黄人。
- 攻击、跳过、不行、克隆、角色牌对子等核心规则与本文一致。
- `不行`必须在目标行动开始前打出；行动开始结算后不能追溯取消。
- 纸质版未规定联网游戏的响应计时、并发指令排序和掉线处理，这些仍需项目自行裁定。

## 1. 游戏概览

- **支持人数**：2～5 人
- **总牌数**：72 张
- **目标**：成为最后一个没有爆炸出局的玩家
- **核心循环**：玩家在自己的回合中打出任意数量的牌，最后抽一张牌结束本次回合
- **淘汰条件**：抽到爆炸小黄人，且无法使用拆弹牌
- **胜利条件**：场上只剩一名存活玩家
- **手牌限制**：没有上限或下限；手牌为零时没有特殊补偿

《爆炸小黄人》是独立游戏。由于牌背不同，官方明确说明它不能与《爆炸猫》的扩展包混用。

## 2. 完整牌组构成

| 牌型 | 数量 | 类型 | 核心作用 |
|------|-----:|------|----------|
| Exploding Minion / 爆炸小黄人 | 4 | 危险牌 | 抽到后必须拆弹，否则出局 |
| Defuse / 拆弹 | 7 | 防御牌 | 抵消一次爆炸，并秘密放回爆炸牌 |
| Attack / 攻击 | 5 | 行动牌 | 不抽牌结束当前回合，下一位玩家承担两回合 |
| Nope / 不行 | 7 | 即时牌 | 取消上一项行动，可用 Nope 取消 Nope |
| See the Future 3x / 预见未来 | 7 | 行动牌 | 私下查看牌堆顶部三张，不能改变顺序 |
| Skip / 跳过 | 6 | 行动牌 | 不抽牌，立即结束一个待执行回合 |
| Shuffle / 洗牌 | 4 | 行动牌 | 随机打乱整个抽牌堆 |
| Draw From the Bottom / 从底部抽牌 | 5 | 行动牌 | 从牌堆底部抽一张并结束一个回合 |
| Minion Character / 小黄人角色牌 | 24 | 组合牌 | 单张无效果；两张同名角色组成对子并随机偷牌 |
| Clone / 克隆 | 3 | 特殊牌 | 复制弃牌堆顶部牌的效果；也可与一张角色牌组成对子 |

角色牌共三种角色，每种 8 张：

- `Kevin & Otto`
- `Stuart`
- `Bob`

不同插画或文案不代表不同规则；服务端只需要按角色牌类型判断是否同名。

## 3. 按人数准备牌组

准备牌组时，先从 72 张牌中移出全部 4 张爆炸小黄人，再按人数筛选普通牌：

| 人数 | 使用的普通牌 |
|-----:|--------------|
| 2 人 | 只使用右上角带 `Gru Tech` 标记的牌，共 31 张 |
| 3 人 | 只使用右上角不带 `Gru Tech` 标记的牌，共 37 张 |
| 4～5 人 | 使用全部普通牌，共 68 张 |

### Gru Tech 标记分布

| 牌型 | 带标记 | 不带标记 | 合计 |
|------|-------:|---------:|-----:|
| 拆弹 | 3 | 4 | 7 |
| 攻击 | 2 | 3 | 5 |
| Nope | 3 | 4 | 7 |
| 预见未来 | 3 | 4 | 7 |
| 跳过 | 3 | 3 | 6 |
| 洗牌 | 2 | 2 | 4 |
| 从底部抽牌 | 2 | 3 | 5 |
| Kevin & Otto | 4 | 4 | 8 |
| Stuart | 4 | 4 | 8 |
| Bob | 4 | 4 | 8 |
| Clone | 1 | 2 | 3 |
| **普通牌合计** | **31** | **37** | **68** |

4 张爆炸小黄人不参与 Gru Tech 子牌组筛选，按玩家人数减一单独加入。

然后依次执行：

1. 从当前普通牌组中取出全部拆弹牌。
2. 每名玩家获得 1 张拆弹牌。
3. 将剩余拆弹牌放回普通牌组。
4. 洗牌后，每名玩家再获得 7 张牌；初始手牌共 8 张。
5. 放入 `玩家人数 - 1` 张爆炸小黄人；多余爆炸牌移出本局。
6. 再次洗牌，形成抽牌堆。
7. 随机或由房主指定起始玩家；回合按顺时针进行。

### 数字版建模要求

每张牌至少需要以下属性：

```text
card_id          唯一实例 ID
card_type        规则类型
character_type   角色牌类型，仅角色牌需要
has_gru_tech     是否带 Gru Tech 标记
```

不能只按牌型数量动态拼出 2 人或 3 人牌组，因为官方牌组筛选依赖每个具体牌实例上的 `Gru Tech` 标记。实现前需要录入实体牌的完整标记清单。

## 4. 回合流程

一名玩家可能因为攻击牌而连续承担多个回合。每个待执行回合均遵循：

1. **出牌阶段**
   - 玩家可以不出牌。
   - 玩家可以依次打出任意数量的牌。
   - 每张牌结算完成后，若回合尚未结束，可以继续出牌。
2. **结束回合**
   - 默认从抽牌堆顶部抽 1 张牌。
   - 抽到普通牌：加入手牌，该待执行回合结束。
   - 抽到爆炸小黄人：进入爆炸结算。
   - 使用攻击、跳过或从底部抽牌，也可以结束当前待执行回合。
3. **推进回合**
   - 若当前玩家仍有攻击造成的待执行回合，则继续由该玩家行动。
   - 否则轮到下一名存活玩家。

## 5. 卡牌详细效果

### 5.1 爆炸小黄人

抽到后必须立即公开。

- 有可用拆弹牌：进入拆弹流程。
- 没有可用拆弹牌：玩家出局。
- 爆炸牌与拆弹牌不能被 Nope 取消。

玩家出局时，将爆炸牌与自己的全部手牌公开放置并移出正常游戏流程。下一名存活玩家继续行动。

### 5.2 拆弹

拆弹牌只在玩家抽到爆炸小黄人时使用：

1. 丢弃 1 张拆弹牌。
2. 玩家选择一个插入位置，将爆炸小黄人秘密放回抽牌堆。
3. 插入时不能查看或重新排列牌堆中的其他牌。
4. 可以放在牌堆顶部、底部或任意中间位置。
5. 完成后，该待执行回合结束。

数字版中，其他玩家只能知道爆炸牌被重新插入，不能看到具体插入位置。

### 5.3 攻击

- 当前玩家立即结束当前回合，不抽牌。
- 下一名存活玩家增加 2 个待执行回合。
- 如果遭受攻击的玩家打出攻击牌，则立即结束其当前待执行回合，并把自己剩余的全部待执行回合加上 2，转移给下一名存活玩家。
- 攻击可以无限叠加。

示例：玩家 B 因攻击需要行动 2 回合。B 在第一个回合立即打出攻击，则玩家 C 需要行动 4 回合。

### 5.4 跳过

- 立即结束当前一个待执行回合，不抽牌。
- 它只消除一个待执行回合。
- 若玩家因攻击需要行动两回合，使用一张跳过后仍需再行动一回合。

### 5.5 从底部抽牌

- 从抽牌堆底部抽 1 张牌，而不是顶部。
- 抽牌后结束当前一个待执行回合。
- 抽到爆炸小黄人时，仍按正常爆炸流程处理。

这张牌不是“先执行效果、稍后仍需抽牌”，它本身完成了该回合的抽牌动作。

### 5.6 预见未来

- 当前玩家私下查看抽牌堆顶部最多 3 张牌。
- 查看后必须按原顺序放回。
- 不结束回合，玩家可以继续出牌，最终仍需以其他方式结束回合。
- 牌堆少于 3 张时，只返回实际存在的牌。

### 5.7 洗牌

- 随机打乱整个抽牌堆。
- 不结束回合。
- 洗牌结果对所有玩家保密。

数字版应使用服务端随机源完成洗牌，客户端不得决定结果。

### 5.8 Nope

- 可以在任何玩家的回合中即时打出。
- 必须在目标行动开始结算前打出；行动已经产生效果后不能追溯取消。
- 取消它前面紧邻的一项行动，使该行动视为没有发生。
- 不能取消爆炸小黄人或拆弹。
- Nope 可以取消另一张 Nope；每多一张 Nope，行动的生效状态翻转一次。

示例：

- `攻击 → Nope`：攻击不生效。
- `攻击 → Nope → Nope`：第二张 Nope 取消第一张 Nope，攻击重新生效。

数字版需要提供明确的响应窗口。在响应窗口关闭前，允许其他存活玩家依次追加 Nope；窗口关闭后再结算最终效果。

根据纸质版“行动开始之前随时打出”的规则，服务端在响应窗口关闭前不得执行目标行动的任何副作用。行动一旦进入结算阶段，就拒绝后续 Nope。

### 5.9 小黄人角色牌

- 单独打出没有效果。
- 同一玩家同时打出两张同名角色牌，可随机抽取另一名存活玩家的 1 张手牌。
- 被偷牌玩家必须由发起者指定。
- 具体被偷到哪一张牌必须随机决定，发起者不能查看或选择。
- 角色牌对子行动可以被 Nope 取消。

本版本没有原版《爆炸猫》中“三张同名牌点名索取指定牌”的规则。

### 5.10 Clone

Clone 是《爆炸小黄人》相对基础版最重要的新牌：

- 通常情况下，Clone 复制它打出前弃牌堆顶部那张牌的规则效果。
- Clone 不能复制另一张 Clone。
- Clone 复制的是规则效果，不会永久改变自身牌型。
- 若弃牌堆顶部是 Nope，Clone 可以在合法响应时机复制 Nope，继续取消链。
- 复制需要目标或选择的行动牌时，玩家仍需提供相应目标或选择。
- 若玩家抽到爆炸小黄人，且弃牌堆顶部为拆弹牌，可以使用 Clone 复制拆弹效果。
- Clone 可以与一张小黄人角色牌同时打出，视为该角色牌的第二张牌，组成对子并随机偷牌。
- 不能仅因为弃牌堆顶部已有其他玩家打出的角色牌，就单独打 Clone 组成对子；角色牌与 Clone 必须作为同一次对子行动一起打出。

### Clone 复制效果时的实现映射

| 弃牌堆顶部效果 | Clone 的行为 |
|----------------|-------------|
| 攻击 | 按攻击牌处理 |
| 跳过 | 按跳过牌处理 |
| 从底部抽牌 | 立即从底部抽牌并结束当前待执行回合 |
| 预见未来 | 查看顶部最多三张 |
| 洗牌 | 洗牌 |
| Nope | 在响应窗口内视为另一张 Nope，继续翻转行动生效状态 |
| 拆弹 | 仅在爆炸结算中可作为拆弹使用 |
| 角色牌 | 不能单独复制历史角色牌组成对子 |
| 爆炸小黄人 | 不可作为主动出牌效果复制 |

## 6. 规则时序与服务端状态机

建议服务端至少使用以下阶段：

```text
WAITING_FOR_PLAYERS
SETUP
TURN_PLAYING
AWAITING_NOPE
RESOLVING_ACTION
AWAITING_DRAW
RESOLVING_EXPLOSION
AWAITING_DEFUSE_POSITION
PLAYER_ELIMINATED
GAME_OVER
```

### 权威状态原则

- 手牌、牌堆顺序、洗牌结果和随机偷牌结果只存在于服务端。
- 客户端发送“意图”，例如打哪张牌、选择谁、插入位置。
- 服务端验证意图、执行规则并广播结果。
- 不应向其他玩家广播手牌内容、预见未来结果或爆炸牌插入位置。

## 7. MVP 必须明确的规则裁定

官方实体规则允许玩家自然交流和即时响应，数字版必须补充确定性规则。MVP 建议采用：

1. **Nope 响应窗口**：可被 Nope 的行动打出后，服务端先暂停该行动并开启固定时长响应窗口；无人追加 Nope 后才开始结算。行动开始结算后不再接受 Nope。
2. **Nope 顺序**：响应按服务器收到顺序记录；最终以 Nope 数量奇偶决定行动是否生效。
3. **Clone + Nope**：仅当弃牌堆顶部为 Nope 且响应窗口仍开放时允许，按另一张 Nope 处理。
4. **Clone + 拆弹**：仅当抽到爆炸牌且弃牌堆顶部是拆弹时允许。
5. **爆炸牌插入位置**：客户端提交 `0..deck_size` 的位置索引；位置仅对提交者可见。
6. **首位玩家**：由服务端随机选择。
7. **玩家操作超时**：MVP 可先不设自动出牌，但必须保留协议错误码；后续再增加超时自动抽牌。

以上第 1、3、5～7 项属于数字版实现裁定，并非中文纸质版逐字规定；后续应作为项目规则写入协议文档。

## 8. MVP 规则范围

第一阶段只支持 2 人完整对局，但规则引擎按 2～5 人设计：

- 使用官方 2 人牌组：带 Gru Tech 标记的 31 张普通牌。
- 每人 1 张初始拆弹牌，再各发 7 张。
- 放入 1 张爆炸小黄人。
- 实现全部十种牌型及 Clone。
- 跑通创建房间、加入房间、准备、开局、行动、抽牌、拆弹、爆炸、结算。

暂不实现：

- 3～5 人大厅匹配流程
- 账号、战绩和持久化
- 断线重连
- 观战
- 自定义牌组或《爆炸猫》扩展包

## 9. 测试用例最低清单

### 初始化

- 2、3、4、5 人牌组筛选和总数正确。
- 每名玩家初始 8 张牌且恰有 1 张保证发放的拆弹牌。
- 爆炸牌数量始终为玩家数减一。

### 回合

- 普通抽牌后结束当前一个待执行回合。
- 攻击正确转移和叠加待执行回合。
- 跳过只消除一个待执行回合。
- 从底部抽牌不会再次要求从顶部抽牌。

### 爆炸与拆弹

- 无拆弹时玩家出局。
- 拆弹后爆炸牌插回指定位置，玩家存活。
- Clone 在合法条件下可以复制拆弹。

### 行动牌

- 预见未来仅向当前玩家返回顶部三张且不改顺序。
- 洗牌改变顺序但保留全部牌实例。
- 角色牌对子只能匹配同名角色。
- 偷牌目标合法且结果来自目标手牌。
- Clone 不能复制 Clone，也不能单独复制历史角色牌组成对子。
- Clone 在合法响应窗口内可以复制 Nope，并正确翻转行动生效状态。

### Nope

- 一张 Nope 取消行动。
- 两张 Nope 恢复行动。
- 爆炸牌和拆弹牌不能被 Nope。
- 被取消的行动不产生任何业务副作用。
